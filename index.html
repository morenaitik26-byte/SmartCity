About our project

SmartCity AI — Smart City Management & Emergency Response Simulator

What we built

A dashboard that turns sample traffic, air-quality, water and incident data into statuses, alerts and recommendations using simple rules.

What we learned

How HTML, CSS and JavaScript work together, and how threshold rules can support decisions in a smart city.

Responsible use

All data is fictional. It does not control real infrastructure or contact emergency services. Real cities need sensors, security and human experts.
